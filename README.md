# Decay releases

Downloads for [Decay](https://decay.aryangarg.com): it quietly archives the browser tabs and app windows you stopped using, and brings any of them back with one shortcut.

**[Download the latest version →](https://github.com/code08-ind/decay-releases/releases/latest)**

- **macOS:** the app isn't notarized yet. The first time, right-click Decay in Applications → **Open** → **Open**.
- **Windows:** SmartScreen may warn about an unknown publisher: **More info → Run anyway**.

Installed copies update themselves from this page. Found a bug or have feedback? [Open an issue](https://github.com/code08-ind/decay-releases/issues).
